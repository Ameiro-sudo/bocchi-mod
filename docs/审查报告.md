### sync/ 说明

`sync/check-layout.py` 是布局常量漂移检测器，与 facts.js 形成校验闭环，逻辑自洽。只比对公式在当前分辨率下的求值，不覆盖 `layout.js` 中 webOnly 的推导值。

### 内存泄漏专项结论

| 类别 | 判定 |
|------|------|
| 事件监听器 | 无泄漏（均挂在静态元素或一次性构建元素上） |
| setInterval | 1 个永不清理（M4） |
| Object URL | 预览路径泄漏（M1），`download` 路径正确 |
| DOM | 无泄漏 |
| localStorage | 每次滑杆/拖拽写入（性能问题，非泄漏） |
